자전거 보관함

대중교통 친화도시 효빈! 시민 여러분의 편리한 자전거 환승을 위해 주요 역마다 대규모 사물함형 보관소를 운영합니다.

사물함형 자전거 보관함 사용 방법

A 자전거 보관 방법

1. 보관 선택

키오스크 화면에서
'자전거 보관' 터치

2. 보관함 선택

화면에서 미사용 중인
파란색 보관함 터치

3. 정보 입력

본인 명의의
휴대폰 번호 입력

4. 인증번호

문자로 전송된
6자리 인증번호 입력

5. 자전거 보관

문이 열리면 보관 후
보관증 수령 및 문 닫기

B 자전거 찾기 방법

1. 찾기 선택

키오스크 화면에서
'자전거 찾기' 터치

2. 보관함 선택

본인이 보관 중인
빨간색 보관함 터치

3. 정보 입력

보관 시 입력했던
휴대폰 번호 재입력

4. 인증번호

새로 전송된
찾기용 인증번호 입력

5. 자전거 회수

문이 열리면 자전거를
꺼내고 문 닫기

노선별 자전거 보관함 설치 현황

역명 보관소 위치 보관 가능 대수 비고 (CCTV 유무)

[TMI] 효빈도시철도 자전거 보관함 로어

  • 3호선 박라미의 아지트: 등산과 액티비티 매니아인 박라미는 주말마다 자신의 고가 산악자전거(MTB)를 3호선 대형 역사 보관함에 맡겨두고 산으로 향합니다. 가끔 인증번호를 까먹어서 관제실에 전화를 걸어 "아따 내 자전거 좀 꺼내도고!" 라며 사투리를 남발해 직원들을 당황하게 합니다.
  • 2호선 하루빈의 퇴근길 썰: 2호선 하루빈은 환경 보호를 핑계로 2호선 순환선을 자전거로 완주하려다 30분 만에 체력이 방전되어, 결국 역사 앞 보관함에 자전거를 박아두고 지하철로 쾌적하게 퇴근했다는 전설이 내려옵니다.
  • 빈효선 전노아의 취미 생활: 빈효선 전노아는 역사 주변에 어지럽게 방치된 공유 자전거와 킥보드를 보관함 주변에 칼각으로 정리하는 기묘한 강박(?)이 있습니다. 특정 역 보관함 주변이 유독 깨끗하다면 전노아가 순찰을 다녀간 흔적입니다.
